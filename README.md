Testimonial Cards
A simple webpage that displays testimonial cards in different styles.
Description
This project shows customer testimonials using 4 different card layouts:

A dark speech bubble card
A light bordered card
A card with a large image on the left and review on the right
A carousel card with navigation arrows and avatar dots
